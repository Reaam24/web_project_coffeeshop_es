# Triple Espresso
# Triple Espresso es una página web para una cafetería que presenta información sobre el establecimiento, sus horarios y ubicación. También incluye un formulario para reservar una mesa, donde el usuario puede ingresar su nombre, número de comensales, fecha, hora y correo electrónico, además de aceptar los términos de uso. El sitio cuenta con navegación interna, enlaces a redes sociales y estados interactivos al pasar el cursor sobre determinados elementos. Para su desarrollo se utilizaron HTML5 para la estructura semántica, CSS3 para los estilos, posicionamiento, Flexbox e interactividad visual, además de Google Fonts para integrar las tipografías Inter y Noto Serif.
# Como mejora futura, se podría agregar un reel o carrusel de fotografías para mostrar las instalaciones, bebidas y alimentos disponibles en la cafetería. También sería útil incorporar un menú digital con precios, validar y procesar las reservaciones mediante JavaScript, mostrar mensajes de confirmación después de enviar el formulario y conectar los enlaces de redes sociales con los perfiles oficiales. Otra mejora importante sería adaptar completamente el diseño a dispositivos móviles y tabletas mediante media queries.
